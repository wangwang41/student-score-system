# 学生成绩管理系统（C++ 控制台）

面向对象程序设计课程实践项目。

## 编译运行

```
g++ -std=c++17 -O2 main.cpp -o main.exe
./main.exe
```

main.exe 要和 stu_users.txt、grade_data.txt 放同一目录。

## 账号

|---|---|---|
| 2025001~2025004 | 123456 | 学生 |

## 功能

学生：看信息、查成绩（总分/平均/绩点/总分排名/单科排名）、导出个人成绩单、改密码。
老师：学生名单/模糊搜人/改电话、单条登成绩（0-100校验）/批量导入 batch_in.txt、各科统计+分数段星号图、导出全班成绩单。
管理员：账号增删停启用重置密码、成绩数据查看/删除、看操作日志。

## 数据文件

- stu_users.txt：账号,密码,姓名,角色(s/t/a),启用(0/1),性别,年级,班级,电话
- grade_data.txt：学号,科目,分数,学期
- batch_in.txt：批量导入用，格式同 grade_data.txt
- log.txt：运行后自动生成，记录操作日志
